# kajenn-orchestra

**Status**: Pre-Alpha · version 0.0.0 reserves the name on PyPI. The orchestration arrives with 0.1.0.

Orchestration for [kajenn](https://github.com/kajenn-org/kajenn): the SPA application, the worker
pool, sticky routing of users to workers, freeze and reassignment.

Based on genropy history and genro-modules.
