# kajenn-orchestra brand assets

| Asset | File | Dimensions |
| --- | --- | --- |
| Logo without lettering | [kajenn-orchestra-mark.png](kajenn-orchestra-mark.png) | 1254 × 1254 |
| Logo with lettering | [kajenn-orchestra-logo.png](kajenn-orchestra-logo.png) | 1145 × 1374 |

Both are transparent PNG files. The selected identity consists of one red coordinating curve and three slender parallel gold curves. The complete logo places lowercase kajenn above the smaller, more widely spaced orchestra line, with visually aligned widths.

See [Visual identity](visual-identity.md) for previews and usage. All other graphic rules follow the [shared kajenn theme guide](https://github.com/kajenn-org/kajenn/blob/main/assets/branding/theme-guide.md). This repository does not define a separate palette or interface theme.

## Light and dark backgrounds

The root README uses `<picture>` with `prefers-color-scheme: dark` to select
[`kajenn-orchestra-logo-dark.png`](kajenn-orchestra-logo-dark.png). The existing
[`kajenn-orchestra-logo.png`](kajenn-orchestra-logo.png) remains the light-mode fallback.

The dark variant uses light lettering on an opaque charcoal background intended
for GitHub's default dark theme. It is not a transparent export: other dark themes
may show a visible rectangular background. These raster variants share the same
1145 × 1374 canvas; they are visually matched, not pixel-identical masters.
The standalone symbol asset is unchanged.
